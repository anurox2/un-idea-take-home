# UN | IDEA | React take home assesment

This project demonstrates performance comparison between direct API calls and cached Context API approach in React.

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Setup Instructions

1. Install dependencies

```bash
npm install
```

2. Start the development server

```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`
